# Recursive-Descent-Recognizer

A hand-crafted recursive descent recognizer in TypeScript.

## Requirements

- [Node.js v26](https://nodejs.org)

## Install

```bash
nvm install 26
nvm use 26
npm ci
```

## Start

```bash
echo The input string | npm start
```
